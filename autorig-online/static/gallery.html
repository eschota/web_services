About these results

Every card is a real public task. AutoRig V3 rigged it from one upload, retargeted the animation clips and checked the result in the background of the viewer. Hover a card to preview the animation; open it to watch the model move in the Unity viewer.

Results are sorted by date, newest first, and the rig type filter narrows the list to one preset. Every task is one viewer with an agent chat, and you can download GLB, FBX, USDZ, a ZIP, a Unity package or a Blender file.

Want the same for your model? Drop it on the home page; the target is a rigged, animated model within one minute from pickup.
