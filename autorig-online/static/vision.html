Use it from your own code

The same model is available over HTTP. wait_seconds holds the response until the answer is ready; leave it out to poll /api/ai/status/<task_id> yourself.

curl -X POST https://autorig.online/api/vision \
  -H "Content-Type: application/json" \
  -d '{
        "prompt": "What is in this picture?",
        "image_url": "https://example.com/photo.png",
        "model": "bonsai2-27b",
        "wait_seconds": 120
      }'
