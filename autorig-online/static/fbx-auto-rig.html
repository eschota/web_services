Unity and Unreal Engine FBX rigging

FBX is the interchange format of game engines and DCC tools. An FBX enters the same V3 conveyor as GLB and OBJ: AutoRig builds the skeleton and skin, retargets the animation clips and opens the result in the viewer. If your FBX already has a skeleton or an animation, its own rest pose is read first. The rigged model exports as FBX, and also as GLB, USDZ, a ZIP, a Unity package and a Blender file.

Engine compatibility:

  • Unity: the FBX imports as a humanoid
  • Unreal Engine: the FBX imports as a skeletal mesh
  • Blender and the web: use the GLB or the Blender file from the same task

FBX rigging features

Humanoid in Unity

A biped exports with a standard humanoid skeleton that Unity understands.

Skeletal mesh in Unreal

The same rig imports into Unreal Engine as a skeletal mesh with its animation clips.

Any pose

No T-pose or A-pose is required. When a biped stands on one leg or steps, the planted leg sets the reference bone lengths.

Textures kept, PBR added

Your materials, textures and UVs are kept. A model without textures gets PBR maps automatically.

Unity vs Unreal Engine rigging

Unity Mecanim

Unreal Animation Blueprint
