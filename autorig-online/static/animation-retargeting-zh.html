重定向就是把为一套骨架制作的动画应用到另一套骨架上。通常这意味着购买动画包、调整比例，并在引擎里重新检查每个片段。AutoRig 替你完成这些：片段会立即重定向到每个新绑定上，并且每个片段都用数值检查。

每个类别一套动画库

每个绑定类别都有自己的动画片段库。以动物为例，包括行走、小跑、慢跑、飞奔、待机、直立、环顾和攻击等。某个类别的参考视频只需生成并做一次质量检查，动作也只需从中提取一次。之后这些片段就可以重复使用：该类别的每个新模型都通过自动重定向把它们应用到自己的骨架上。没有人需要为某一个模型手工制作动画。

程序化片段只是兜底方案，仅在动画库中没有该类别的片段时使用。

马科模型（马、鹿、斑马）使用蹄子踩稳地面的步态：行走、小跑和飞奔时蹄子始终不离地。鸟类有翅膀片段，手部有带每根手指关节的手部片段。

带数值质检的自动重定向

  1. 拟合。首先让绑定贴合你的模型：使用它自己的比例和关节位置。
  2. 重定向。把动画库片段的动作转移到这套骨架上。
  3. 检查。每个片段都要通过数值形变检查。关节位置、蒙皮撕裂和肢体碰撞会在查看器后台测量。
  4. 展示。绑定完成后片段立即在查看器中播放，目标是在开始处理后一分钟内得到已绑定并带动画的模型。

重定向为什么常常效果不好，AutoRig 怎么处理

  • 比例不同。在应用任何片段之前，绑定会先贴合你的模型，所以手臂很长或腿很短的模型都有自己的骨骼长度。
  • 基础姿势不同。你不需要 T 姿势，绑定会按模型当前的样子生成。当双腿没有并排站立时，支撑腿是两条腿共同的参照。
  • 关节扭曲和权重不佳。肩部和髋部附近的关节位置与蒙皮撕裂是测量出来的，而不是凭肉眼判断。
  • 脚底打滑。马科的步态让蹄子始终踩稳地面。

查看器中的自定义片段

每个任务在查看器中都有一个片段集。你可以把自己的片段加进去，与动画库片段并列，并在同一套绑定上播放。如果某个关节需要调整，可以在蓝图模式（B）中编辑骨骼：最后一次编辑 15 秒后，查看器会重新绑定，也可以点按钮立即重新绑定。骨架确认只是提供，绝不强制，所以动画不会等待它。

导出

可以把绑定和动画片段下载为 GLB、FBX、USDZ、ZIP、Unity 包，或用于 Blender 的文件。指南涵盖 Unity 中的 GLB、Unreal 中的 FBX 和 GLB 与 FBX 对比，Blender 插件则把同样的流程带进 Blender。

在引擎中使用这些片段和你自己的动画包

如果你想在引擎内重定向自己的动画包，导出的绑定可以当作普通骨架使用。

  • Unity（人形模型）。导入带绑定的 FBX，把 Rig 的 Animation Type 设为 Humanoid，检查 Avatar 映射，把片段导入为 Humanoid，然后在 Animator Controller 中使用。
  • Unreal。重定向会根据引擎版本使用骨架和 IK 绑定。思路相同：先定义一次映射，再在兼容的绑定之间复用动画。

常见问题

需要 T 姿势吗？

不需要。绑定会按模型在任意姿势下拟合，片段再重定向到这套绑定上。

可以用我已有的动画包吗？

可以。导出绑定后在你的引擎中重定向动画包，或在查看器中把它们添加为自定义片段。

哪些类别有动画片段？

九个类别各有自己的动画库：双足、四足、马科、鸟类、蛇形、怪物、多肢体、手部和车辆。如果某个类别的动画库里暂时没有对应片段，就使用程序化片段兜底。

需要多长时间？

快速绑定只需几秒，片段会立即重定向。目标是在开始处理后一分钟内得到已绑定并带动画的模型。
