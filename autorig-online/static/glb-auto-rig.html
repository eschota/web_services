What is GLB auto rigging?

GLB (glTF Binary) is a compact format for web and game assets. A GLB enters the same V3 conveyor as every other input: AutoRig reads the geometry and the textures, picks the rig category, builds the skeleton and skin and retargets the animation clips. Your own textures are kept, and a GLB without textures gets PBR textures automatically.

Perfect for:

  • WebGL applications and web viewers
  • Unity and Unreal Engine projects
  • VR/AR experiences
  • Game development
  • 3D visualization

GLB rigging features

Rig in seconds

The fast rig builds the skeleton and skin from the geometry. The target is a rigged, animated model within one minute from pickup.

Any pose, any category

Characters, animals, birds, hands and cars: each category has its own skeleton template and clip library. A T-pose is not required.

Animation clips at once

Clips are retargeted automatically, with a numeric check on each one. The skeleton confirmation is offered in the viewer, never required.

Textures kept, PBR added

A GLB keeps its materials, textures and UVs through rigging. Without textures it gets PBR maps automatically.
