输入一张图，输出一个完整角色

大多数 image-to-3D 工具止步于网格。你拿到一个静态模型，绑定仍然要自己熬夜做。AutoRig 把图片当作整条流水线的起点：图片变成带贴图的 3D 模型，模型获得骨骼和蒙皮权重，然后动画库被重定向到它身上。这一切都作为一个任务、一个进度页面交付。

路由决策只做一次，就在上传之后。网站查看你的图片，判断其中是否有能承载骨骼的角色。如果有，你会得到生成加绑定。如果没有——载具、道具、建筑，或四肢与身体粘连的角色——你依然会得到一个完整的 PBR 3D 模型，因为无论如何模型都是你付费购买的东西。

工作流程，一步一步来

上传之后，四个阶段自动运行，无需你再做任何操作。

  1. 拖入图片

    打开 AutoRig 首页，把 PNG、JPG 或 WEBP 文件拖到上传区。一张图片对应一个角色。需要先登录，因为生成会从账户扣费。

  2. 网站判断它看到的是什么

    检测会判断图片中是否有四肢离开躯干的 T-pose 或 A-pose 角色。这只决定路线：可绑定的图片进入生成加绑定，其余的只进入生成。

  3. 生成 3D 模型

    图片送往 GPU 农场，返回时是带 PBR 材质的贴图网格，并经过重拓扑成为可用几何，而不是类似扫描的原始表面。

  4. 模型被绑定并加上动画

    拟合骨骼、求解蒙皮权重，并把动画库重定向到新角色上。随后任务会发布 GLB、Unity FBX、HDRP unitypackage、Blender 文件和预览视频。

任务完成后你会拿到什么

完成的角色任务会发布一整套交付文件，而不是单个文件。本页示例每个都交付了 9 到 17 个产物。

已绑定的 GLB

面向 Web 的原生格式。可以在任务页面的浏览器查看器里播放，也能直接放进 three.js、Babylon、Godot 或任何 glTF 流水线。

含动画的 Unity FBX

骨骼网格，内含已烘焙的重定向动画集，可直接用于 Mecanim。

HDRP unitypackage

为 High Definition Render Pipeline 接好材质的 Unity 包，导入后角色不会变成粉色。

Blender 文件

Blender 视角下的场景，可用于权重绘制、重拓扑修补，或导出为上面列表之外的格式。

预览视频

角色播放动画的渲染片段——就是本页嵌入的那些视频。

什么样的图片可以绑定

检测器要找的是可读的身体，而不是艺术水准。一张干净 T-pose 的粗略草图，胜过一张摆着夸张动作姿势的精美渲染图。

  • 角色面向镜头，直立并大致居中。
  • 手臂离开躯干——T-pose 时水平伸直，A-pose 时向下张开。
  • 双腿分开，之间有可见的空隙。
  • 全身都在画面内，包括手和脚。
  • 背景简洁，至少不要与角色轮廓混在一起。

如果图片里不是角色

没有任何图片会被拒绝。无法承载骨骼的图片依然会生成带贴图的 PBR 3D 模型——你只是拿到没有骨骼和动画的模型。这是针对每张图片的路由决策，而不是失败提示。

一次上传多张图片

一次拖入多张图片，每张都会成为自己的任务并一起排队。上传区支持多文件选择并按顺序启动，因此一组概念图可以在一轮里变成一组已绑定角色。只拖一个文件会进入该任务页面；拖多个则会进入你的任务列表。

大家真正会问的问题

开始之前需要有 3D 模型吗？

不需要。这正是本页的重点——一张图片就够了。如果你已经有 GLB、FBX 或 OBJ，直接上传即可，完全跳过生成。

角色必须是 T-pose 吗？

T-pose 和 A-pose 都可以，只要四肢与身体分开。姿势决定的是是否尝试绑定，绝不会决定你能否拿到模型。

需要多长时间？

本页的示例从头到尾大约需要 20 到 50 分钟，其中包含在农场队列中的等待时间。任务页面会显示实时进度，你可以关闭标签页——任务会继续运行。

如果我上传的不是角色怎么办？

你会得到那件东西的带贴图 PBR 3D 模型。检测只是给任务分流，并不会拒绝它。

可以一次绑定多个角色吗？

可以。在上传区选择多张图片，每张都会成为独立任务并分别计费。

需要账户吗？

从图片生成角色需要账户，因为 Unlimited 月度订阅会绑定到账户。上传已有 3D 模型并运行绑定仍无需订阅。
