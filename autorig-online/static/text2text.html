Use it from your own code

wait_seconds holds the response until the answer is ready; leave it out and poll /api/ai/status/<task_id> instead.

curl -X POST https://autorig.online/api/text2text \
  -H "Content-Type: application/json" \
  -d '{
        "prompt": "Name three colours.",
        "model": "bonsai2-27b",
        "max_output_tokens": 512,
        "wait_seconds": 90
      }'
