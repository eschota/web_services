U3D YouTube Upload API

Отдельный провайдер загрузки на U3d Indie Game Developer (@unlim3d). Он не использует канал, OAuth-токен или автоматическую очередь AutoRig.

Проверяю готовность API…

Открыть skill.md для агента

Ключ показывается только администратору AutoRig и не является admin API key.

Инструкция агенту

Передайте агенту прямую ссылку https://autorig.online/dev/youtube/skill.md и отдельный U3D agent key. На любом компьютере используется один и тот же API-контракт.

curl -X POST "https://autorig.online/dev/api/youtube/videos" \
  -H "Authorization: Bearer U3D_AGENT_KEY" \
  -F "file=@video.mp4;type=video/mp4" \
  -F "title=Video title" \
  -F "description=Video description" \
  -F "tags=3D,game development" \
  -F "privacy_status=public"

Успех: HTTP 201, channel_matches_expected: true и фактический privacy_status в ответе. Shorts и длинные ролики идут через один endpoint.
