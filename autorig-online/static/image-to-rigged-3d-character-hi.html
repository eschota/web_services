एक तस्वीर अंदर, पूरा character बाहर

ज़्यादातर image-to-3D tools mesh पर ही रुक जाते हैं। आपको static model मिलता है और rigging फिर भी आपकी शाम खा जाती है। AutoRig तस्वीर को पूरी pipeline की शुरुआत मानता है: image एक textured 3D model बनता है, model को skeleton और skin weights मिलते हैं, और उस पर animation library retarget होती है। यह सब एक ही task और एक ही progress page के रूप में आता है।

Routing का फैसला एक ही बार होता है, upload के तुरंत बाद। साइट आपकी तस्वीर देखती है और तय करती है कि उसमें ऐसा character है या नहीं जो skeleton उठा सके। अगर है, तो आपको generation के साथ rigging मिलती है। अगर नहीं — vehicle, prop, building, या ऐसा character जिसके limbs body में मिले हों — तब भी आपको पूरा PBR 3D model मिलता है, क्योंकि model के लिए तो आपने वैसे भी भुगतान किया है।

एक ही image से बने characters

नीचे हर preview इस साइट पर एक पूरा हो चुका public task है। हर एक की शुरुआत एक uploaded तस्वीर से हुई और अंत animations वाले rigged character पर। Play दबाएं, फिर result देखने के लिए task page खोलें।

ये clips वही preview videos हैं जो pipeline हर पूरे हुए task के लिए render करती है। इनमें generated character सचमुच retargeted animation चला रहा है, न कि static mesh का turntable।

यह कैसे काम करता है, step by step

Upload के बाद चार stages बिना आपके कुछ किए चलते हैं।

  1. तस्वीर drop करें

    AutoRig का home page खोलें और PNG, JPG या WEBP file को upload zone पर drop करें। एक image यानी एक character। Sign in ज़रूरी है, क्योंकि generation account से charge होती है।

  2. साइट तय करती है कि वह क्या देख रही है

    Detection जांचता है कि image में torso से अलग limbs वाला T-pose या A-pose character है या नहीं। इससे सिर्फ़ route तय होता है: riggable तस्वीरें generation plus rigging में जाती हैं, बाकी सब सिर्फ़ generation में।

  3. 3D model generate होता है

    तस्वीर GPU farm पर जाती है और PBR materials वाले textured mesh के रूप में लौटती है, जिसे scan जैसी raw surface की जगह usable geometry में retopologise किया जाता है।

  4. Model rig और animate होता है

    Skeleton fit होता है, skin weights solve होते हैं, और animation library नए character पर retarget होती है। इसके बाद task GLB, Unity FBX, HDRP unitypackage, Blender files और preview video publish करता है।

Task पूरा होने पर क्या मिलता है

पूरा हुआ character task एक file नहीं, पूरा delivery set publish करता है। इस page के examples ने हर एक में 9 से 17 artifacts दिए।

Rigged GLB

Web-native format। Task page के browser viewer में चलता है और सीधे three.js, Babylon, Godot या किसी भी glTF pipeline में चला जाता है।

Animations के साथ Unity FBX

Retargeted animation set के साथ baked skeletal mesh, Mecanim के लिए तैयार।

HDRP unitypackage

High Definition Render Pipeline के लिए wired materials वाला Unity package, ताकि import पर character गुलाबी न दिखे।

Blender files

Blender की नज़र से scene — weight painting, retopology touch-ups, या ऊपर की list से बाहर किसी format में export के लिए।

Preview video

Character के animations चलाने की rendered clip — वही videos जो इस page पर embedded हैं।

कौन सी तस्वीर riggable होती है

Detector readable body ढूंढता है, art quality नहीं। साफ़ T-pose में बना rough sketch उस सुंदर render से बेहतर है जिसमें character नाटकीय action pose में मुड़ा हो।

  • Character camera की तरफ़ है, सीधा खड़ा और लगभग बीच में।
  • Arms torso से दूर हैं — T-pose में सीधे बाहर, या A-pose में नीचे की ओर कोण पर।
  • Legs अलग हैं, उनके बीच साफ़ gap दिखता है।
  • पूरा body frame में है, hands और feet सहित।
  • Background सादा है, या कम से कम silhouette में घुलता नहीं।

और जब तस्वीर character नहीं होती

कुछ भी reject नहीं होता। जो तस्वीर skeleton नहीं उठा सकती, वह भी textured PBR 3D model देती है — आपको बस skeleton और animations के बिना model मिलता है। यह हर तस्वीर के लिए routing का फ़ैसला है, failure message नहीं।

एक साथ कई तस्वीरें

कई images एक साथ drop करें — हर एक अपना अलग task बनती है और साथ में queue होती है। Upload zone multi-file selection लेता है और उन्हें क्रम से शुरू करता है, तो concept sheets का एक सेट एक ही बार में rigged characters का सेट बन सकता है। एक file drop करें तो उस task के page पर पहुंचते हैं; कई drop करें तो अपनी task list पर।

जो सवाल लोग सचमुच पूछते हैं

शुरू करने के लिए 3D model चाहिए?

नहीं। यही तो इस page की बात है — एक तस्वीर काफ़ी है। अगर आपके पास पहले से GLB, FBX या OBJ है, तो उसे सीधे upload करें और generation पूरी तरह छोड़ दें।

क्या character का T-pose में होना ज़रूरी है?

T-pose और A-pose दोनों चलते हैं, बस limbs body से अलग होने चाहिए। Pose यह तय करता है कि rigging की कोशिश होगी या नहीं; यह कभी तय नहीं करता कि आपको model मिलेगा या नहीं।

इसमें कितना समय लगता है?

इस page के examples में शुरू से अंत तक लगभग 20 से 50 मिनट लगे, जिसमें farm queue में इंतज़ार का समय भी शामिल है। Task page live progress दिखाता है, और आप tab बंद कर सकते हैं — task चलता रहता है।

अगर मैं ऐसा कुछ upload करूं जो character नहीं है?

आपको उसी चीज़ का textured PBR 3D model मिलेगा। Detection काम को route करता है, reject नहीं करता।

क्या मैं एक साथ कई characters rig कर सकता हूं?

हां। Upload zone में कई images चुनें — हर एक अपना task बनेगी और अलग से charge होगी।

क्या account चाहिए?

तस्वीर से character generate करने के लिए account चाहिए क्योंकि Unlimited Monthly account से जुड़ता है। मौजूदा 3D model rig करना subscription के बिना उपलब्ध रहता है।
