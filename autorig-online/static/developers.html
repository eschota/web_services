Developer API

Use the AutoRig HTTP API to create tasks from a link or an upload, poll until the task is done, then download the rigged model, animation files and related files via stable URLs. A task is the same V3 task as on the site, and its result is the V3 viewer with animation clips and exports.

Base URL: https://autorig.online

How a task works in V3

  • A task starts from any input: a 3D model (GLB, FBX, OBJ or a ZIP with textures), a picture, a picture of a car, or text. The calls below create a task from a link or an upload; the examples use a model link.
  • The V3 conveyor builds the skeleton and skin from the geometry in seconds and retargets the animation clips at once. Quality checks run in the background.
  • The result is the task page https://autorig.online/task?id=TASK_ID: the V3 viewer with the clips and the AI agent chat.
  • The viewer offers GLB, FBX, USDZ, ZIP, Unity package and Blender downloads. The endpoints below have stable URLs, and cached-files lists every file the task has with its download URL.

Authentication

Send your secret key on every request using either header: Authorization: Bearer <key> or X-API-Key: <key>. Keys look like ar_<prefix>_<secret>. Signed-in users and anonymous visitors (with a browser session cookie) can create keys from this page or Buy credits.

Main endpoints

Method Path Notes
POST/api/task/createmultipart form: source=link, input_url, type=t_pose
GET/api/task/{id}Task status and metadata
GET/api/task/{id}/prepared.glbPreview / prepared model GLB
GET/api/task/{id}/animations.glbCombined animations GLB
GET/api/task/{id}/animations.fbxAnimations FBX (Unity etc.)
GET/api/task/{id}/model.glbBase model GLB
GET/api/task/{id}/cached-filesJSON list of cached files and download URLs

Typical flow

  1. POST /api/task/create with a link (JSON with input_url, or multipart with input_url or a file).
  2. GET /api/task/{id} until the status is done or error.
  3. GET /api/task/{id}/cached-files for the list of files.
  4. Download with GET on prepared.glb, animations.glb, animations.fbx or model.glb.

Examples

Replace TASK_ID and YOUR_API_KEY. For link-based input, use a publicly reachable URL to your GLB/FBX/OBJ.

curl -X POST "$BASE/api/task/create" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"input_url":"https://example.com/model.glb"}'

curl -X POST "$BASE/api/task/create" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "input_url=https://example.com/model.glb"

curl -H "Authorization: Bearer YOUR_API_KEY" "$BASE/api/task/TASK_ID"

curl -o out.glb -H "Authorization: Bearer YOUR_API_KEY" "$BASE/api/task/TASK_ID/prepared.glb"
