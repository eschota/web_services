开始 FBX Unreal 绑定

Unreal Engine 流程通常使用 FBX 来导入骨骼网格和动画。如果你有一个没有骨架的静态 FBX 角色，最快的做法是：先运行自动绑定，再把得到的带骨架 FBX 作为 Skeletal Mesh 导入 Unreal。AutoRig 根据模型自身的几何形状生成骨架，所以角色不必摆成 T 姿势。

第 1 步：准备 FBX（无需 T 姿势）

骨架会按任意姿势贴合几何形状。如果双足角色的两条腿站姿不同，以站立的腿决定骨骼长度；如果 FBX 本身已有骨架或动画，则使用它自带的静止姿势。以下做法仍然有帮助：

  • 如有可能，在你的 DCC 软件中应用变换
  • 绑定前统一缩放和单位
  • 没有翻转的法线或非流形几何
  • 让贴图与模型放在一起：模型自带的贴图不会丢失，没有贴图的模型会自动生成 PBR 贴图

第 2 步：在线自动绑定 FBX

在 autorig.online 把 FBX 拖入上传区。任务会立即在 3D 查看器中打开。快速绑定几秒内生成骨架和蒙皮，模型所属类别动画库中的片段会重定向到骨架上，质量检查（关节位置、蒙皮撕裂、肢体穿插）在后台持续进行。任务完成后，下载适用于 Unreal 的 FBX 导出文件；也可以下载 GLB、USDZ、ZIP 和 Unity 包。

为 Unreal 绑定 FBX

第 3 步：导入 Unreal

  1. 在 Unreal 中打开 Content Browser → Import。
  2. 选择带骨架的 FBX 导出文件。
  3. 选择 Skeletal Mesh（而不是 Static Mesh）。
  4. 如果包含动画，请启用 Import Animations。
  5. 导入后打开 Skeletal Mesh 资源进行预览。

第 4 步：重定向（可选）

如果想复用其他角色的动画，可以用 Unreal 的重定向工具在不同骨架之间映射动画。绑定和比例越干净，重定向就越顺畅。

Unreal 常见问题

网格缩放不对

缩放不一致源于单位不统一。如有可能，请在绑定前于 DCC 软件中统一缩放。

蒙皮瑕疵

自动蒙皮已尽力而为，并且每个绑定都会在后台进行数值形变检查。厚重的衣物、盔甲或特殊的拓扑仍可能产生变形。对于主角，请把自动绑定当作基础，再手动打磨权重。

骨骼朝向警告

Unreal 对骨架一致性要求很严。为所有角色使用同一条导出路径（同一个工具），以避免意外的骨骼轴向问题。

提示：如果同一个问题反复出现，请在查看器中打开任务，检查骨架（Blueprint 模式，按 B 键），修正骨骼并重新绑定。更多内容请阅读姿势指南、GLB 与 FBX以及动画重定向。
