# Roadmap: единый набор API генерации контента на своей ферме

Статус: **TODO — принято к работе, не начато** (зафиксировано по обсуждению 2026-09-01).

Важно: это НЕ «умный агент». Сначала — набор стабильных API генерации контента,
работающих на нашей ферме в общей очереди с перераспределением нагрузки.
Агент-«сборщик сцен» (настройка света, bloom, кривых, SSR и т.п.) — отдельный
будущий проект, который станет обычным потребителем этих API и блокирован ими.

## Мотивация

- AutoRig должен уметь собирать сцены; для этого нужен инструментальный слой:
  генерация изображений, видео, звука, 3D-моделей, персонажей, животных.
- Домен `free3d.online` продлеваться не будет (~$34/год). Библиотеку Free3D
  (~16 700 продуктов, архив на worker-0001) нужно перенести в раздел
  autorig.online и **автоматически пополнять при каждой успешной генерации**.
- Сейчас каждая возможность живёт в своём углу (renderfin, конвертер-фермы,
  free3d-сервер) со своей очередью и своими сбоями; нагрузка не
  перераспределяется между типами работ.

## Что уже есть (инвентаризация 2026-09-01)

| Возможность | Состояние | Где живёт |
|---|---|---|
| Изображения (Flux T-pose/A-pose + маски) | есть | renderfin → ComfyUI-фермы (Raptor, F15, 4090) |
| 3D из изображения (Hunyuan3D 2.1) | есть | конвертер-фермы F1/F2/F11/F13, `/api-converter-glb/generate-3d` |
| Персонаж целиком (image→rigged character) | есть | `backend/renderfin/character_gen.py`: flux → hunyuan → turntable → авто-submit в риг |
| Животные (12 видов, 30 клипов, 24 варианта) | есть | animal-rig пайплайн конвертеров |
| Видео | частично | turntable MP4 (Chromium на VPS), Unity HDRP видео на фермах; LTX 19B стоит на free3d-сервере и в общую очередь НЕ включён |
| Звук | **нет** | отсутствует полностью — нужен новый API (TTS/SFX/музыка — выбрать модели) |
| Библиотека ассетов | частично | `/api/free3d/*` проксирует free3d.online — умрёт вместе с доменом |
| Общая очередь | частично | для rig-задач уже есть workload-брокер (`workload_leases`, `workload_node_states`, preemption, queue_class); renderfin — отдельная очередь; free3d/LTX — вне очереди |

## Целевая архитектура

1. **Единый фасад** `POST /api/generate/{kind}`, kind ∈ `image | video | audio |
   model3d | character | animal`. Общий контракт задачи: идемпотентный ключ,
   `queue_class`/приоритет, статусы `created → processing → done|error`,
   стандартные ретраи и Telegram-алерты — по образцу риг-пайплайна.
2. **Один брокер очереди** поверх всех типов воркеров (GLB-конвертеры, ComfyUI,
   LTX, будущий audio): веса, классы, вытеснение (preemption уже реализовано для
   rig), карантин воркеров, перераспределение нагрузки между типами работ.
3. **Durable artifact cache для всего**: результаты генерации складываются так
   же, как deliverables ригов (см. существующий artifact cache), и отдаются
   nginx с HTTP Range.
4. **Library (бывш. Free3D)**: раздел на autorig.online; каталог, превью и GLB
   мигрируют с worker-0001/free3d-сервера; каждая успешная генерация
   (постер + GLB + LLM-метаданные уже есть у задач) автоматически публикуется в
   библиотеку.

## Этапы

- **v0** — инвентаризация и этот документ (готово).
- **v1** — фасад `/api/generate` для image (Flux) и model3d (Hunyuan) поверх
  существующего workload-брокера; общая очередь для этих двух типов.
- **v2** — видео (turntable + LTX с free3d-сервера) в той же очереди;
  автопополнение Library из завершённых генераций.
- **v3** — audio API (выбрать модели: TTS, SFX); интеграция в фасад.
- **v4** — миграция каталога Free3D и выключение домена; редиректы не нужны
  (домен просто истекает).

## Открытые вопросы / риски

- Дата истечения free3d.online — уточнить в регистраторе; миграцию каталога
  закончить ДО неё (после истечения worker-0001.free3d.online и face-rig прокси
  `/api/task/{id}/face-rig/analyze-head` тоже потеряют хостнейм!).
- Диск way-fr уже ~94% (61 ГБ свободно при резерве 65 ГБ, artifact cache
  периодически на паузе) — до миграции 16.7k продуктов нужен сторедж-план.
- Face-rig воркер живёт на `worker-0001.free3d.online` — при отказе от домена
  перевесить на `*.freestock.online` или туннель.
- Выбор моделей звука не сделан.
