OneClick3D API

Submit a ZIP containing a 3ds Max scene and textures, follow its progress, and download converted results.

OneClick uses its own API keys and task history. An AutoRig API key does not authenticate here.

Creating a new key revokes your previous OneClick API keys. Save the new key securely; it is shown once.



Create a task from a ZIP URL
curl https://oneclick3d.xyz/api/task/create \
  -H "Authorization: Bearer YOUR_ONECLICK_API_KEY" \
  -F "source=link" \
  -F "input_url=https://your-host.example/scene.zip"
The response contains task_id. Open /task?id=TASK_ID to view the task on the site.
Follow progress
curl https://oneclick3d.xyz/api/task/TASK_ID \
  -H "Authorization: Bearer YOUR_ONECLICK_API_KEY"
Statuses are created, processing, done, or error. Ready previews can appear while processing continues. Use progress for phase progress and the URL lists for actual discovered files.
Upload a file
The website uses resumable chunk uploads: POST /api/upload/init, POST /api/upload/chunk, GET /api/upload/status, and POST /api/upload/complete. Archives up to 10 GiB are accepted when disk reserve and upload quota permit. Resume an existing upload rather than creating a new session for each retry.
Downloads use /api/file/TASK_ID/download/FILENAME with your key. Preview access and paid file access follow the same rules as the website.
