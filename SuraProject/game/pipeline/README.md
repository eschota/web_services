# Scene pipeline

1. Concept stills (approved per level).
2. Depth via ControlNet Z_depth on autorig.online/nodes (graph 7f85772d24f8 for the jet cabin).
3. Low-poly Blender block-out calibrated by the depth map; cameras for look-around.
4. Video clips from the autorig.online video graphs; Sura via the swap recipe (../../PIPELINE.md).
