# До острова · первый уровень

Игровой прототип на русском: 40 сцен, 6 финалов, 13 иллюстраций. Главный герой — взрослый 18-летний сын владельца частного самолёта; бортпроводнице 20 лет. «Мира» — рабочее имя, не окончательный выбор внешности. Персонажи остаются за кадром. Уровень заканчивается посадкой или неграфическим Game Over, второго уровня нет.

## Запуск

Из этой папки: `python3 -m http.server 8000 --directory dist`, затем открыть http://localhost:8000. Нужен HTTP-сервер, поскольку сценарий загружается через fetch. Зависимостей и сборки нет; Node 20+ нужен только для тестов (`node test.mjs`).

## Управление

Нажать действие или 1–4. «Назад» возвращает последнее решение вместе с состоянием. «Сохранить» записывает ручное сохранение в localStorage этого браузера на этом устройстве; оно не синхронизируется. «Продолжить» загружает его. Новая игра требует подтверждения и не удаляет ручное сохранение. Сломанное/устаревшее сохранение не подменяет текущую игру. История ограничена последними 150 решениями.

Отдельная страница `scenario.html`: полный граф, перетаскивание/прокрутка, масштаб, поиск по сценам и репликам, детали переходов и условий. Ссылка `#node_id` открывает конкретную сцену. `story.json` можно скачать прямо из схемы.

## Архитектура

`dist/story.json` — единственный источник реплик, переходов, условий, эффектов и финалов; игра и схема читают один файл. `engine.js` — чистые функции состояния. `game.js` — интерфейс игры, `map.js` — граф сценария. Состояние содержит булевы признаки, а не видимый «счётчик соблазнения». Они ставятся идемпотентно: повторное исследование не даёт очков. Все циклы исследования добровольные. Для взаимного приглашения требуется доверие из нормального разговора. Тайна требует телефона, конверта и информации о рейсе. После отказа можно беспрепятственно уйти; гибель требует ещё двух сознательных агрессивных выборов и предупреждена.

Финалы: контакт, поддержка, неловкое знакомство, нейтральная посадка, тайна отца, гибель. На снижении игрок может выбрать, какую из полученных линий сделать главным итогом перелёта, либо нейтральное завершение. Это прототип ветвления, а не автоматическая оценка личности.

## Изображения

Использованы утверждённые кадры C01–C06 и S01–S06, переведённые из PNG в WebP quality 88 без изменения композиции. Начало использует утверждённый тёмный кадр пробуждения. Это неподвижные иллюстрации, не 3D-рендерер. Портрет или силуэт бортпроводницы намеренно не выбран. Первоначальные PNG не дублируются в архиве. Внешние шрифты необязательны: при недоступности Google Fonts работают системные запасные.

## Проверки

`test-results.json` содержит результат перебора 120 906 состояний: все 40 сцен и все 6 финалов достижимы; восстановление предыдущего состояния и сериализация проверены на каждом исследованном переходе; ошибки сохранения, ссылки, изображения и синтаксис проверены. Полноценная визуальная проверка в браузере не проводилась. Проверки не являются доказательством отсутствия всех интерфейсных ошибок.
