# AutoRig Cloth

AutoRig Cloth is AutoRig.online's runtime for **secondary motion**: it animates hair, skirts, capes,
coat tails, tails, ribbons and accessories on rigged characters by simulating their bone chains.
It fills the role that BoneCloth / BoneSpring-style assets such as Magica Cloth 2 play in Unity
projects, but it is our own code, so it can ship inside AutoRig.online character packages and be
sold on its own.

The AutoRig **Regen** pipeline writes a `<model>.autorig-cloth.json` manifest next to every rigged
FBX/GLB. The manifest names the chains, their presets and the body colliders. The Unity package reads
it and builds the complete setup, so a customer can drop an AutoRig character into a scene and see
its hair and clothes move without any manual work.

## Status

**v0.1.0 — preview.** Everything below exists and is covered by the automated checks. It has not
been run inside the Unity Editor yet: the Unity-side code is compile-checked against the Unity
reference assemblies, and the behaviour is verified through the engine-independent core's unit
tests.

- Unity package `online.autorig.cloth` (Unity 2021.3+, no dependencies), installable from git:
  `https://github.com/eschota/web_services.git?path=/autorig-cloth/package`
- Pure C# solver core: Verlet integration at a fixed 90 Hz with an accumulator, interpolated
  animated pose, attach-frame inertia, teleport reset, shape restoration, angle limits, stretch,
  `none` / `open` / `loop` links between chains, sphere / tapered-capsule / plane colliders with
  tag masks, drag, gravity and turbulent wind. Deterministic, allocation-free per step,
  struct-of-arrays data ready for a Burst port.
- Unity layer: `ClothBoneGroup`, colliders, `ClothWind`, `ClothPreset`, auto-created
  `AutoRigClothManager` (zero GC per frame).
- Setup tools: manifest v1 loader (`AutoRigClothSetup`, `ClothManifestLoader`), humanoid body
  collider builder, chain detection from bone names; inspectors and a `Tools/AutoRig Cloth` menu
  with Undo.
- Procedural demo sample and a usage guide (`package/Documentation~/index.md`).

## Layout

```text
autorig-cloth/
  spec/                     cloth manifest v1: specification, JSON schema, example (hero)
  package/                  the Unity package (UPM root)
    Runtime/Core/           engine-independent solver, math, manifest data and rules
    Runtime/Components/     MonoBehaviours and ScriptableObjects
    Runtime/Setup/          manifest loader, humanoid collider builder, chain detector
    Editor/                 inspectors, menu items, gizmo helpers
    Samples~/ProceduralDemo empty-scene demo
    Documentation~/         usage guide
  tests/
    AutoRig.Cloth.Core.Tests/  xUnit tests of Runtime/Core (compiled without UnityEngine)
    compile-check/             Runtime, Samples and Editor compiled against Unity reference DLLs
    run-checks.sh              runs everything; non-zero exit on failure
```

Run the checks (needs the .NET 8 SDK and access to nuget.org):

```bash
autorig-cloth/tests/run-checks.sh
```

## Roadmap

- **v0.2 — MeshCloth via a proxy mesh.** Simulate a low-poly proxy (skirt tube, cape sheet)
  generated by Regen and skin the render mesh to it: real cloth folds, triangle-based collision,
  self-collision for capes. Manifest v1 gains optional proxy fields.
- **v0.3 — Burst / Jobs.** Port the core to Unity.Mathematics + Burst with `TransformAccessArray`
  reads and writes; multi-threaded groups; distance and visibility LOD.
- **Web viewer port.** A JavaScript/TypeScript port of the core for the AutoRig.online three.js
  viewer, reading the same manifest, so the site previews cloth exactly as Unity plays it.
- **Asset Store packaging.** Licence terms, sample characters from AutoRig.online, documentation
  site, demo scenes per render pipeline, Unity 2022/6 validation.

## Кратко (по-русски)

AutoRig Cloth — наш собственный рантайм вторичной анимации для риггованных персонажей: волосы,
юбки, плащи, хвосты, ленты и аксессуары симулируются на цепочках костей (по духу как BoneCloth /
BoneSpring в Magica Cloth 2). Пайплайн AutoRig Regen кладёт рядом с моделью файл
`<модель>.autorig-cloth.json`; Unity-пакет `online.autorig.cloth` читает его и сам строит цепочки,
пресеты и коллайдеры тела — персонаж «оживает» без ручной настройки. Версия 0.1 — превью: ядро на
чистом C# (детерминированное, без аллокаций, покрыто тестами), компоненты Unity, загрузчик
манифеста, автоопределение цепочек, коллайдеры для гуманоидов, редакторские инструменты и демо.
В Unity Editor пакет ещё не запускался — Unity-код проверяется компиляцией против референсных
сборок Unity. Дальше: v0.2 — MeshCloth через прокси-меш, v0.3 — Burst/Jobs, порт на JS для
веб-вьюера, упаковка для Asset Store.
